## 当前产品方向与选型状态

- 可独立作为普通论坛使用；卡／资源是应用形态，作品经明确关联接入，不要求所有帖子依附作品。
- 每张卡同时提供介绍与下载、即时聊天频道、帖子论坛。
- 论坛支持楼层式和即时式；楼中楼只一层，引用具体消息。
- Go 自研业务内核＋成熟组件复用；不将历史候选作为默认主干，具体配套仍为工程建议。
- 用户身份统一映射，作品权限由一个业务权威管理。
- 公网 API／文件访问使用 HTTPS，WebSocket 使用 WSS。
- 数据库与实时层同样按需求重新选择；历史试验数据仍隔离保存。
- 数万在线目标需要实际负载验证，研究结果不视为容量验收。
