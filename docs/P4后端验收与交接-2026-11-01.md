## 本轮发现和处理

- Go SDK 的 GetState 不能永远返回过期游标：缓存缺口会触发 112 并重新取状态。本轮先真实复现了固定游标导致的重试，再改用普通 SDK 重连测试恢复失败与 HTTPS 回补；接入契约明确了正确顺序，未修改或削弱第三方 SDK。
- 完整回归发现上一轮 API 已升 0.9.1，但某个旧测试仍断言 0.9.0。本轮把断言同步成 0.9.1，保留版本约束，没有删除测试。此前五项修复记录中的完整回归发生在该版本字段更新前，不能当作新版本所有测试均已覆盖；本轮重新跑全量收尾。
- 不在当前没有生产证据时扩大消息缓存、增加全局连接数或改变群限额。本轮证明功能和恢复正确性，没有承诺吞吐或生产撤权 SLA。

## 两项真实接入门槛

当前真实配置按用户明确决定留空，正式上线前再准备。所需配置、状态与验收统一维护在 [上线清单](正式上线待填与验收清单.md)；这两项已从当前收尾待办转为上线前待办。真实秘密保存在受限本地／部署配置中，不写进聊天或版本库。

### E01：真实 R2

提供独立测试私有附件桶、公开表情桶与公开 HTTPS 域名；配置字段沿用 `.env.example`。配置进入本机环境后显式执行：

```powershell
$env:ODYSSEIA_TEST_EXTERNAL_R2 = '1'
go test -tags external -run '^TestExternalR2' -count=1 -v ./internal/blob
```

会各写一个人工像素文件，私有对象路径在随机 `conversations/p4-acceptance/<uuid>/`，公开对象在随机 `acceptance/p4/<uuid>/`，只清理自己创建的精确键，不列举或删除现有对象。测试检查私有签名下载／无签名 S3 API 拒绝／删除，以及公开域名读取与 immutable 缓存。日志不输出密钥或签名 URL。

公开 CDN 可能在删除源对象后仍缓存这个无害测试像素。私有桶的未签名 S3 API 拒绝，也不等于已经审计所有公开域名／桶设置。R2 生命周期、定时清扫部署、真实上下载链路和桶隔离仍须记录真实结果。参考 [R2 预签名 URL](https://developers.cloudflare.com/r2/api/s3/presigned-urls/)。

### E02：真实 ZITADEL

需要真实测试实例的 issuer、API audience、JWKS、必要 CA，以及同一测试账号取得的访问令牌与 ID token，保存在本地环境中。显式执行：

```powershell
$env:ODYSSEIA_TEST_EXTERNAL_IDP = '1'
go test -tags external -run '^TestExternalIdentityProvider$' -count=1 -v ./internal/tokenauth
```

检查真实 HTTPS discovery／JWKS 与配置一致、访问令牌可验证、错误 audience 拒绝、ID token 不能当 API 访问令牌。该检查只验证真实供应商的令牌消费兼容，不冒充注册／登录／PKCE 页面验收。

正式配置必须核对令牌类型与本后端的 API 访问令牌契约，不能因为模拟 issuer 通过就认为可以无条件替换，也不能为了接通而放松 ID token 隔离。参考 [ZITADEL 应用令牌配置](https://zitadel.com/docs/guides/manage/console/applications-overview)与[签名密钥说明](https://zitadel.com/docs/guides/integrate/login/oidc/webkeys)。

上述两组外部测试本轮实际结果是 **SKIP，尚未验收**。没有令牌或存储凭据时显式开启会失败，不会静默使用模拟服务。
