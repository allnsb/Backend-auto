# P4-c Discord 式自定义表情

更新时间：2026-10-31。本文记录 HTTP 0.9.0／第十三项迁移。论坛、频道、文字会话、图片／语音附件和约 7 天清扫保持原有行为。不做转码、已读回执和频道复杂权限。

## 已确认的产品决定

1. 自定义表情分全站和论坛两级。名称在各自范围内唯一，规则是 `^[A-Za-z0-9_]{2,32}$`。删除后名称可以再用。
2. 文件只接受 png、apng、gif、webp。动画由容器判断：GIF 多于一帧、PNG 的 `acTL` 帧数大于 1、WebP 的 VP8X 动画位。JPEG、AVIF、语音和 SVG 拒绝。不缩放、不转码。
3. 默认单文件不超过 256KiB，边长不超过 128。配置只能把这两项调低，或把边长调到不超过 256。数据库天花板是 256KiB 和 256 像素。
4. 消息里的引用是 `<:name:id>`（静态）和 `<a:name:id>`（动画）。发送时名称、动画标志和可用性必须与目录一致。论坛表情只能出现在**同一个 `forum_id`** 的话题和频道里；同时属于另一个论坛也不把表情带过去。会话（私聊和群聊）只接受全站表情。不引入 Discord Nitro 式的跨服使用。格式不像引用的文字保持原样。一条消息最多 50 个记号，这是写路径的限制。0.9.0 之前已经落库的正文没有这个上限；读取时如果一条消息无法按这个上限投影，就保持该条原文，不能让整页历史失败。
5. 响应在 `emojis` 里附上仍可用的表情：id、名称、动画标志、范围、内容类型、公开 URL、宽高和字节数。删除后，后续 HTTPS 读取把对应记号改成 `:name:`，并从 `emojis` 去掉。库里的正文仍保留原记号。已经发出的实时事件不改写；断线后的 HTTPS 历史是权威结果。
6. 表情对象放在单独的公开桶，键是 `emoji/v1/<哈希前两字节>/<sha256>.<扩展名>`，`Cache-Control` 为 `public, max-age=31536000, immutable`。会话附件继续走私有桶和短时预签名，`Cache-Control` 仍是 `private, no-store`。删除表情只标 `deleted_at`，不删对象：同一内容哈希可能被多条目录复用，不可变缓存也不应被一次删除打穿。
7. 论坛表情由该论坛有效角色优先级不低于 moderator（200，含 owner）的成员管理。有效角色复用协作面解析，取目录组与论坛角色中的最高者；上传、幂等重放和删除都在事务锁后重新确认。普通成员可以列表和使用，不能上传或删除。全站表情的上传和删除需要目录 owner。身份组里的 `owner` 是论坛角色模板，不是全站管理员；在出现平台管理员之前，目录 owner 是 `ODYSSEIA_EMOJI_SITE_OWNER_IDS` 里的本地用户 UUID。名单为空时，没有人能写全站表情。
8. 每个论坛同时存活的表情最多 50 个，全站最多 200 个。一条消息最多 50 个自定义表情记号。这是目录上限，不是频道权限。

## 参考来源

| 来源 | 本刀怎么用 |
|---|---|
| [Discord Emoji Resource](https://docs.discord.com/developers/resources/emoji) | 上传上限 256KiB；推荐 128×128；`animated` 是表情自身的属性。创建表情需要 `CREATE_GUILD_EXPRESSIONS`。本刀把论坛侧对应到 moderator 及以上。不引入 Discord Nitro：论坛表情不出本论坛，会话里不能用论坛表情。 |
| [Discord 表情格式说明](https://discord.com/blog/beginners-guide-to-custom-emojis) | 文件类型含 JPEG、PNG、GIF、WebP、AVIF，客户端会帮忙缩放。本刀不接受 JPEG／AVIF，也不缩放：服务端只保存通过检查的原容器。 |
| [discord-api-types 的表情正则](https://github.com/discordjs/discord-api-types/blob/main/globals.ts) | `<(a)?:name:id>`。名称用本目录的 `[A-Za-z0-9_]{2,32}`，id 用小写 UUID，不用 snowflake。 |
| [WebP RIFF 容器](https://developers.google.com/speed/webp/docs/riff_container) | 位号从 MSB 0 起。VP8X 第一个标志字节里，动画位的值是 `0x02`。没有 VP8X 的简单 WebP 视为静态。 |
| [RFC 8246](https://www.rfc-editor.org/rfc/rfc8246) `immutable` | 内容哈希放进对象键之后，缓存可以按 URL 长期保存。响应头是 `public, max-age=31536000, immutable`。 |
| 现有 `blob.Store` | 会话桶保留 `Put`／`PresignGet`／`Delete`。表情使用旁边的 `PublicStore`：同一个 S3 客户端构造，另一只桶，另一套缓存头。不把预签名 GET 当成公开 CDN。 |

没有引入 libvips、bimg 或新的图像库。宽高和动画沿用 P4-b 已锁定的标准库与 `golang.org/x/image/webp` v0.47.0。没有新的 Go 依赖。

## 数据与迁移

第十三项迁移 `00013_custom_emoji.sql` 只新增 `odysseia.emojis`。不改消息正文、不改 Outbox、不改分区，不要求排空。

- `scope` 为 `site` 或 `forum`。论坛表情必须有 `forum_id`，全站表情必须为空。
- 活着的名称唯一：全站按 `name`，论坛按 `(forum_id, name)`。部分唯一索引，删除后的行不占名字。
- 幂等是 `(created_by, request_id)`。同一键配上不同的范围、名称或文件返回 409。键对应的行已经删除时，重放返回 404，不会把表情复活。
- 字节、边长和对象键都有数据库天花板。进程配置只能更严。

回滚是 `DROP TABLE`。表里已有行时，这会丢掉目录；对象还在公开桶里。没有自动清对象。

运行身份在原有授权之外需要：

```sql
GRANT SELECT, INSERT ON odysseia.emojis TO odysseia_runtime;
GRANT UPDATE (deleted_at) ON odysseia.emojis TO odysseia_runtime;
```

先迁移，再启动会写表情的 API。旧进程不读这张表，除非消息正文里已经有自定义表情记号。

## API

OpenAPI `info.version` 为 0.9.0。

| 方法 | 路径 | 行为 |
|---|---|---|
| GET、POST | `/v1/emojis` | 全站目录。POST 要 `Idempotency-Key` 和目录 owner。 |
| GET、DELETE | `/v1/emojis/{emoji_id}` | 读取一条。论坛表情只给该论坛成员。DELETE 只删全站表情。 |
| GET、POST | `/v1/forums/{forum_id}/emojis` | 论坛目录。非成员 404。POST 要 moderator 及以上。 |
| DELETE | `/v1/forums/{forum_id}/emojis/{emoji_id}` | 删本论坛的一条。 |

上传是 `multipart/form-data`，字段 `name` 和 `file`。不看客户端给的 Content-Type。超限 413／`body_too_large`，类型不对 415／`unsupported_media_type`，边长、坏文件或坏名称 422／`invalid_input`。同名 409／`emoji_name_taken`。目录满 409／`emoji_catalog_full`。成员上传论坛表情 403／`permission_denied`。

发消息时引用不可用，返回 422／`invalid_emoji`。话题和频道只接受本论坛表情和全站表情。会话只接受全站表情；在会话里引用论坛表情同样是 `invalid_emoji`。写路径仍拒绝超过 50 个记号。读路径遇到无法投影的旧正文时跳过该条，整页继续返回。正文页缓存仍只保存追加后的原文；投影在缓存之后做，所以删除立刻出现在下一次 HTTPS 读取里。

## 配置

API 启动时 `ODYSSEIA_EMOJI_R2_BUCKET` 和 `ODYSSEIA_EMOJI_PUBLIC_BASE_URL` 必填，缺一不可。未设置的账号、密钥、endpoint 和 region 沿用会话桶的 `ODYSSEIA_R2_*`。桶名不能和会话桶相同。

| 变量 | 含义 |
|---|---|
| `ODYSSEIA_EMOJI_R2_BUCKET` | 公开桶。**启动必填**，且不能等于 `ODYSSEIA_R2_BUCKET`。 |
| `ODYSSEIA_EMOJI_PUBLIC_BASE_URL` | 公开 https 前缀。**启动必填**。无查询、无用户信息、无结尾斜杠。响应里的 URL 是 `{前缀}/{对象键}`。 |
| `ODYSSEIA_EMOJI_R2_ACCOUNT_ID` 等 | 可选。一组都空则复用会话桶凭证；写了其中任意一项就要把账号和两把密钥写全。 |
| `ODYSSEIA_EMOJI_MAX_BYTES` | 默认 262144，最大 262144。 |
| `ODYSSEIA_EMOJI_MAX_EDGE` | 默认 128，最大 256。 |
| `ODYSSEIA_EMOJI_SITE_OWNER_IDS` | 逗号分隔的本地用户 UUID。空名单不能创建全站表情。 |

公开桶不要套用 `conversations/` 的 8 天生命周期。表情键前缀是 `emoji/`。
